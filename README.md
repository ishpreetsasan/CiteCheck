# Samples Directory

This folder holds reproducible test JSON scenarios demonstrating each audit outcome:
- `scenario_pass.json` (Decision: PASS)
- `scenario_revise.json` (Decision: REVISE)
- `scenario_block.json` (Decision: BLOCK)
- `scenario_human_review.json` (Decision: NEEDS_HUMAN_REVIEW)
